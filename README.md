# 무대 투표 (Stage Vote)

동아리 공연에서 **곡마다 공연이 끝난 뒤 "좋았어요 ♥"를 누르는** 관객 투표 웹앱입니다.
외부 패키지 없이 Node.js(18 이상)만 있으면 실행됩니다.

| 주소 | 용도 |
|---|---|
| `/` | 관객 화면 (휴대폰) |
| `/admin` | 운영 콘솔 (비밀번호 필요) |
| `/screen` | 무대 스크린/빔프로젝터용 대형 화면 (QR 코드 포함) |

## 투표 방식
- 2개 팀 × 5곡 = 10곡 (곡 수·팀 배정·순서는 콘솔에서 자유롭게 수정)
- 곡마다 **공연 시작 → 투표 열기 → 마감** 순서로 진행
- 투표가 열린 곡에만, **기기당 곡마다 1번** 투표 가능 (취소 불가)
- 팀 점수 = 그 팀 5곡의 득표 합
- 결과는 콘솔에서 "결과 공개"를 켜야 관객 화면·대형 화면에 표시됨 (그 전엔 운영진만 봄)

## 로컬 실행
```bash
ADMIN_PASSWORD=원하는비번 node server.js
# → http://localhost:3000
```

## Render 배포 (참고 사이트와 같은 방식)
1. 이 폴더를 GitHub 저장소에 올립니다.
2. Render → **New → Web Service** → 저장소 선택
3. 설정
   - Runtime: Node
   - Build Command: (비워두거나) `npm install`
   - Start Command: `npm start`
   - Environment Variables: `ADMIN_PASSWORD` = 운영진 비밀번호 **(꼭 설정하세요)**
4. 배포되면 `https://○○○.onrender.com` 이 관객용 주소, 뒤에 `/admin` 붙이면 콘솔입니다.

### ⚠️ Render 무료 플랜 주의
- **15분 동안 접속이 없으면 서버가 잠들고**, 깨어날 때 30초~1분 걸립니다.
  → 공연 시작 10분 전쯤 콘솔을 열어 두면 계속 깨어 있습니다 (콘솔이 1.5초마다 갱신).
- 무료 플랜은 서버가 재시작되면 저장 파일(`data.json`)이 사라질 수 있습니다.
  → 공연 중에는 문제없지만, **공연이 끝나면 바로 "결과 CSV 다운로드"로 백업**하세요.
  → 확실히 보관하려면 유료 플랜의 Persistent Disk를 붙이고 `DATA_FILE=/var/data/data.json` 환경변수를 설정하세요.

## 당일 체크리스트
1. 콘솔에서 행사명·팀 이름·10곡(팀/제목/공연자) 입력 후 저장
2. 리허설 때 몇 명이 직접 투표해 보기
3. **본 공연 전에 "전체 투표 초기화"** (리허설 표 삭제)
4. 대형 화면(`/screen`)을 스크린에 띄워 QR 안내
5. 곡마다: 공연 시작 → (공연 끝나면) 투표 열기 → 30초~1분 뒤 마감
6. 마지막 곡 후 "결과 공개" 켜기 → CSV 다운로드로 백업

## 중복 투표 방지 수준
기기 쿠키 + 브라우저 저장소로 막습니다. 시크릿 창이나 다른 브라우저를 쓰면 한 번 더 누를 수 있어요.
동아리 공연 규모에서는 보통 충분하지만, 상금이 걸린 경쟁이라면 입장 시 나눠주는 코드 방식 등을 추가로 고려하세요.
